# 手机 GUI 1.2.1 验证记录

日期：2026-09-19。Android versionCode 为 6。

## 改动

- 统一电脑端青绿色、浅灰背景、信息卡片、圆角输入栏及线形图标。默认浅色，保留已有及同步传入的主题。
- 手机导航拆为聊天、供应商、设置；聊天记录使用可关闭的抽屉，宽屏常驻显示。
- 供应商卡片显示当前选择、接口、模型数量及编辑入口；聊天栏可直接编辑当前供应商、模型和设备密钥。
- 设置按界面、通用聊天偏好、手机与电脑同步分组。切换页面保留聊天草稿。
- 输入栏跟随可见视口；Android 开启 adjustResize。编辑表单独立滚动，标题和保存按钮保持可见；修正短视口中入场动画越过底边的情况。
- 保留聊天历史节点、滚动位置及减少动态效果支持；后台输出完成时不强制把正在阅读旧消息的用户拉回底部。

## 验证结果

- `npm test`：6 项通过，覆盖聊天持久化、真实桌面 SQLite 往返、离线队列、同步期间修改、错误重试、账号隔离和异常响应。
- `node tests/mobileUi.mjs`：在 Edge 运行生产构建。验证首次默认浅色、首次添加供应商、获取和修改模型、发送回复、历史重开、模型及深色偏好保留、切页草稿、抽屉隔离交互。
- 320/360/390/768/1040 像素五种宽度下，聊天、供应商、设置和编辑弹窗均无水平溢出。长供应商名、长模型 ID 与长描述没有挤出操作按钮。
- 390 × 420 的短视口模拟键盘出现，输入栏和编辑弹窗的保存按钮保持可见。减少动态效果模式正常；测试期间无渲染器异常。
- 用长会话和延迟返回的测试回答验证阅读位置：用户滚动到旧消息后，回答完成仍保留原来的滚动位置。
- `npm run android:sync`、Gradle `assembleRelease assembleDebug` 成功。正式包及 Compat 包的 v1/v2 签名校验通过，证书分别与已发布的 1.2.0 对应版本一致。
- APK 内网页资源逐字节匹配经过 GUI 验证的 `dist`；applicationId 保持不变，versionCode 由 5 增至 6。

## 实际限制

当前没有连接 Android 真机或模拟器。网页的触屏尺寸与键盘视口模拟不等同于厂商输入法、系统安全区、后台恢复及原生网络请求验收；这些需要在设备上继续验证。
