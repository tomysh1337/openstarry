# OpenStarry Bridge · Edge 手动加载

当前扩展版本：**0.4.1**。发送成功时返回已核对的消息 ID、消息数和会话 ID，供本机持久化；同一条已确认消息的折叠或显示文字变化不再仅因字符串不一致而中断。真正的新消息或会话切换仍报 SESSION_CHANGED。保留网页正文增量、父子并行、思考同步和文件下载。

已加载过扩展时：退出旧验收应用，重新打开 start-manual.cmd；在 edge://extensions 点 OpenStarry Bridge 的“重新加载”，确认版本为 0.4.1，再刷新扩展关联的 ChatGPT 标签页。保持原配对和普通 Edge 登录即可。

首页服务入口下方、IDE 输入区上方常驻子 Agent 任务面板，每约两秒更新状态、已接收字数、工具次数、当前工具、正文预览和耗时；已完成或失败的任务保留入口。点击可读完整分页结果和停止任务。已有失败任务保留原错误，复测需要新建一次任务，不自动重发旧请求。页面布局变化的真实原因及修复效果仍以用户手动复测为准。

首页和 IDE 选择 GPT 网页版后，输入框内可切换“深度思考”，发送前扩展会设置网页“思考”。试发一条要求分段回答的问题：应用应在网页生成中出现增量，结束后显示完成。若网页保留旧未发送草稿，先自行保存或清空；扩展会保留草稿并给出提示。出现错误时应用与扩展都会显示具体原因，确认不明的消息不会自动重复发送。

回复中的文件按钮通过原 ChatGPT 会话下载：应用点击“下载 文件名”后，扩展核对会话和回复，再触发原文件链接并显示普通 Edge 标签页。查看 Edge 下载列表确认保存结果；文件失效需在网页重新生成。仅支持已观测到的 sandbox:/mnt/data/ 文件引用；旧回复若没有保留引用，请在原网页下载。不会自动下载所有文件。

正文 MutationObserver 保存两次读取之间实际出现的新增字符；连接检查不消费这些记录。应用收到即显示，没有后置打字队列；网页一次更新多个字时按实际批次回传，存在页面、传输和写盘延迟，不承诺每字一个网络包。保留 256 条/约 128 KiB，超限合并为最新快照。

应用回复上方展开工具详情可查看实际 OpenStarry MCP 请求、回复及耗时。子 Agent 使用独立 ChatGPT 会话，共享文件策略，最多两个与父任务并行；新会话中连接器是否启用需用户核对。安全等级和容器审批在本机 UI，扩展未新增 Cookie/debugger/下载 API 权限。

此扩展是本项目的本地开发版本，尚未上架扩展商店。它使用普通 Edge 中的 ChatGPT 登录，在应用提交消息后操作扩展关联的标签页。实际网站兼容性待手动验证。

1. 关闭旧 OpenStarry 验收窗口和旧专用 Edge；保留平时使用的普通 Edge。
2. 在普通 Edge 地址栏输入 `edge://extensions`，开启“开发者模式”，点击“加载解压缩的扩展”，选择本目录（包含 manifest.json）。
3. 重新运行仓库 tmp/home-web-manual-20260925/start-manual.cmd。首页选择“GPT 网页版”，点击“连接 Edge / 复制配对码”。
4. 在 Edge 工具栏打开 OpenStarry Bridge，粘贴配对码，点击“连接并打开 ChatGPT”。新标签页沿用该普通浏览器的登录；若页面仍显示验证或错误，请先反馈实际状态。
5. 回应用点“刷新连接”。看到“Edge 扩展已连接”及网页就绪后，再手动发送测试问题，观察首页真实首段、完成、续聊和停止；随后测 IDE 仅提问。

配对码只用于这台电脑的应用和扩展，请勿发到聊天或仓库。扩展不读取 Cookie、不使用 debugger、不操作验证挑战、不修改代理，也不接受网页对它的外部调用。只关联它创建的标签页；有未发送网页草稿时保留草稿并提示。断开扩展或退出应用不会关闭普通 Edge 或删除聊天。

当前测试入口的 API 后端为 fixture，GPT 网页来源为真实页面。已有独立文件 MCP 的 0922-A 读取成功与当前应用项目是两条验收记录；IDE 文件工具仍需配置正确项目连接器。

扩展代码更新后，在 edge://extensions 点击该扩展的“重新加载”，然后刷新它关联的 ChatGPT 标签页。单纯重新加载扩展不刷新已打开页面里的旧 content script。
