## 处理的问题

- 模型初始化 watcher 清空持久化值：只在用户实际切换供应商时清空模型。
- IDE 被组件启动遮罩挡住：IDE 与设置可提前进入。
- 移动离线动态模块缓存及 Origin Vary 不匹配：缓存构建资源清单并按资源 URL 查找。
- 网页预览嵌套 frame 存在空白：独立 sandbox 文档发出就绪握手后在同一受限 frame 渲染，重复预览与 Electron CSP 路径均通过。
- 取消 Agent 提问后继续执行：取消直接终止本轮工具循环。
- 自动化测试创建文件时读取到上一编辑器：等待新文件面包屑及草稿状态后保存，避免测试在异步切换中输入旧编辑器。
